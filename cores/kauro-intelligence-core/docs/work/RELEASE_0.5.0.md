# Release record 0.5.0 (closure of package B03)

Subject reviewed and rejected: `v0.4.0` (commit `1c97fa6`, review `ic-b03-d25a9074bef9`: 10 BLOCKING, 2 MAJOR). Closure design:
`docs/design/B03-closure-plan.md`; cases and evidence classes: `docs/design/B03-case-map.md`; mandates: `docs/design/B03-mandates.json`.
The tree was built on `ic/b03-design` in three stages (ten mandates, each tests first) and integrated on `ic/b03-integration`.

- Versions (D3-VER-1), moved once: package `kauro-intelligence-core` 0.5.0, envelope 2.0.0, proposal 2.0.0, prompt bundle 1.2.0, compiler
  contract 2.0.0, run ledger 2.0.0, candidate configuration 2.0.0, validation receipt 2.0.0. Model policy, memory contract and benchmark
  format are unchanged (1.0.0, 1.0.0, 1.1.0). Migration Core stays the vendored 2.0.1 release; the renamed 2.0.3 has no published
  release and is not re-pinned. `docs/COMPATIBILITY_MATRIX.md` has the 0.5.0 table and keeps the 0.4.0 one as history.
- Integration (this record's mandate): the three rows below marked `INTEGRATION` — S036 over the twelve families in three modes, S095 under a
  grant that cannot admit every task, R2-037 across all twelve families. Tests first at `3bbd561`: S036 and R2-037 passed on
  `ic/b03-stage-2` (no FAMILY_NOT_PLANNED disposition remained; regression guards), S095 failed because the planned tasks after a stop by the
  grant had no outcome; the fix is `5aee8d8`. The packed-tarball consumer check gained a vendor-mode run over the twelve families
  (`tools/consumer-check.mjs`), and the sabotage inventory the lot `b03-closure.mjs` (6 mutations): 311 in all, the 175 of v0.4.0 and the
  136 of the closure.
- Every row below is a test of this repository that goes through the public `run()` (or a public export) with the real Migration Core in the
  host's validation port; the model is a labelled fake, the funded grant the labelled in-memory admission: evidence class SIMULATED unless a
  row says EXECUTED_LOCAL. Rows citing the tests of `v0.4.0` are in the case map and unchanged; the PLATFORM rows belong to B08.
- What stays open, by case: the IC cases marked PARTIAL in the case map wait for B08 (commands CMD020-CMD022, the durable journal on PostgreSQL,
  the shared CostGrant) or B04 (the live provider: bytes, headers, request identity, qualification). Nothing simulated counts as live (A4).
- Verification of this tree is a run, not a sentence: `npm run gate`, `npm run sabotage` (the whole inventory killed, report
  `tmp/sabotage-report.json` bound to the commit and a clean tree) and `npm run design:check` on Windows and on Linux, and the CI run for the
  same head; the independent Codex review (A4 c) runs on that exact commit afterwards.
