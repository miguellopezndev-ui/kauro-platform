# Threat model — IC-1, closed by the B03 closure (0.5.0)

Assets: customer source data (never leaves the host), the agency's decisions, the frozen Migration Core semantics, the run ledger, scoped memory, and the owner's provider budget. Adversaries: a compromised or hallucinating model, a hostile dataset (headers, values, memory text engineered to steer the model), a careless or hostile host caller, a stale or forged validation port, a defect in this tree, and a gate that accepts weak evidence.

Each row names the control that fails closed, the evidence that it does, and the mutation in `tools/sabotage-inventory/` whose survival would prove the control absent. Rows marked ◆ were repaired or added after the independent audit of `b6fcbaf` (`docs/work/IC1_CORRECTION.md`).

## Residual risk accepted in IC-1

- The transport gateway is exercised against fakes; the real adapter, IAM and data-control evidence are IC-2 (§72). The request carries no `temperature` and no `metadata`: six members only (`model`, `max_tokens`, `system`, `messages`, `output_config`, `tools: []`), and the ledger correlation travels beside the request as `TransportCorrelation`, which the benchmark capture forwards unchanged. What IC-2 confirms against the endpoint is acceptance of `output_config` for the pinned model.
- The classifier is rule-based with a compact name list and label vocabulary; recall and precision are measured against the corpus in IC-2. Unlisted vocabulary is masked (precision cost), never sent (no recall cost on privacy).
- Recovery after a crash waits out the dead owner's lease: a redelivery inside the remaining window (at most `WORKER_LEASE_MS`, 120 s) is refused `WORKER_NOT_OWNER` without a call, and the host queue must retry after it — a queue that drops the attempt on that refusal strands it until a later delivery. The lease itself is fenced and renewed (T30); the queue is not relied on to arbitrate between live workers.
- HTTP 429/5xx carry no proof of non-billing and stay ambiguous at full reservation size until IC-2 supplies provider evidence.
- The sabotage inventory is a fixed set of 311 mutations: the 175 of `v0.4.0` (benchmark 34, compiler 10, core 25, kernel 36, privacy 50, transport 20) and the 136 of the B03 closure (accounting 10, cap-identity 25, cap-review 8, cap-structure 9, cap-values 21, closure 6, config-effects 10, kernel-boundary 15, kernel-journal 21, plan-compiler 6, stage-1 5), counted by `tools/sabotage.mjs`'s own inventory listing; it proves the named controls exist, not that no other defect exists.
- The twelve capability families are exercised offline: every model decision comes from a labelled fake (SIMULATED), the funded grant is the labelled in-memory admission, and the validation port is the host adapter over the real Migration Core. The live usefulness of the families is the provider qualification of B04; the durable journal, the shared CostGrant and the commands that start, cancel and plan an audit are the host's, B08's. The canonical model states no option list, no required flag and no external id, so a CLEAN_ONLY run asks six of the twelve families (`test/b03-closure.test.ts` says which).
- The configuration stays CREATE_ONLY: the effect of an identity strategy is source-side proof (authoritative external ids), and destination matching for UPSERT belongs to the execution packages. The design is made against the vendored Migration Core 2.0.1 configuration schema; the renamed 2.0.3 release has no published artifact, and B04 verifies the consumed bytes when it is re-pinned.
- The compact rule reads tokens written with letters, digits and the separators `_ - . / :`. A digit-bearing token with other punctuation (`Zq7#kL`, `name#1234`) is neither a code nor a handle by it and stays UNKNOWN: refused, but by the fail-closed default rather than as personal data. Vocabulary words that are also surnames beside a digit (`Price7`, `Day2`) are words by the rule, as they are alone (R2R-PC-03); the list and label tie-break does not extend to compact tokens. Option *labels* are discarded by `contract-adapter.ts` before transport; the classifier verdict on them is a regression guard, not option-label transport minimization, and IC-05 coverage is not claimed complete.
