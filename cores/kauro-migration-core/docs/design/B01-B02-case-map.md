## Status legend

Migration Core is a library with no database and no server. Its product code path is the public
engine (`src/index.ts`, the CLI adapter) reading real bytes; there is no PostgreSQL in it.

| status | meaning here |
|---|---|
| `EXECUTED_LOCAL` | The public engine path runs in `npm test` (`verify.log` of `159f964`: 1740/1740) on real input bytes, with independent literal truth and a control. |
| `SIMULATED` | The proving run goes through a fake (fake GitHub transport, a synthetic stand-in for a live importer). |
| `PARTIAL(<pkg>)` | The engine half is proven here; the clause named in the row belongs to the platform package given, and is not claimed. |
| `PLANNED(<M#>)` | Not proven at `159f964`. The mandate named writes the test first; the title is fixed here so the re-review can grep it. |
| `PLANNED(evidence)`, `PLANNED(post-publication)` | The local part has landed. What is left is an evidence-stage or post-publication run that cannot happen inside `npm test`; the row flips when that record exists. |

Commit = the commit that introduced the proving test (all present at `159f964` and passing in its
`verify.log`). Planned titles carry the case id in brackets. A golden title reads
`golden corpus > <case> > <it>`; an adversarial title reads `<case>: <expected.json title>`.
