Source: docs/design/B15-B17-B18-local-plan.md section 1 (verdict table), section 4 (await table), sections 3 and 5; built on main 99266f52. A row cites a real test (title copied from the file by tooling) only when that test exists on this branch; every other row names its planned test alias (T1..T7 of the plan) and is NOT_EXECUTED until its lane lands, so no evidence is claimed that does not exist.
