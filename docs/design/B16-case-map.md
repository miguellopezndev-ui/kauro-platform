# B16 — case map

Every case of package B16 (`node tools/package-brief.mjs B16`: 61 cases, gate G-TENANT and its neighbours) mapped to the tests on `main` that
demonstrate its expected outcome, its status, and what the check observes. Plan: the B16 lanes L1..L8; this file is the evidence and the
reservation of what is still open. Every cited title is copied from the test file by tooling, never typed by hand.

`tools/test/b16-case-map.test.mjs` reads this file: every B16 case of the registry (`packages/contracts/registry/program.json`)
appears exactly once, and every cited title occurs verbatim in its cited file.

Status classes: **DONE EXECUTED_LOCAL** — the cited tests demonstrate the whole case against the real API, PostgreSQL 17 and the runtime
roles. **OPEN -> L<n>** — the lane that owns the missing cell, with its class; a cited test of an OPEN row demonstrates only the half the
last column names. **PART(B14|B15|STAGE-RELEASE)** — the provider or later-package half that B16 cannot demonstrate.

Totals: 61 cases — 43 DONE, 18 OPEN. L5 executes the local half of CMD038 and R2-048 (PARTIAL; the S3 presign is B15); L6 closes R2-074 and its restore cells locally (S065 PARTIAL). R2-054 and R2-055 closed by L7 (PR #96, main 56d1e15). L4 closes CMD054, CMD055, R2-050 and S071 locally; R2-049 keeps its provider half open (BLOCKED_OWNER), its local SIM half is cited.
