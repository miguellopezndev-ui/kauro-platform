Every problem a served command may answer (`COMMAND_OUTCOMES`). The api's send guard refuses any other problem on the route
(`422 INTEGRITY_FAILURE RESPONSE_CONTRACT_VIOLATION`, handed to the internal-error sink), and `apps/api/openapi.json`
documents the same entries per status (`x-kauro-outcomes`). `current`: the problem carries the current safe version and
state — always, sometimes, or never (—). Frontends branch on code and reason, never on the title.
