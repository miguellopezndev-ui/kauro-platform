# B07 — case map

Every case of package B07 (registry `program.json` B07 `caseIds`, gate G-UPLOAD, owner 09) mapped to the tests that demonstrate
its expected outcome, to what a sealed check observes, and to the later package that owns any clause B07 cannot demonstrate.
Design: `docs/design/B07-upload-source-lifecycle.md` (decisions `D-*`, commands §11, pipelines §12). The state/command/event
matrix, including the four B07 machines and the specified B07 commands and routes with their outcome catalogues, is generated in
`docs/design/B06-state-command-event-matrix.md` (`tools/matrix.mjs`, checked by `pnpm run verify`).

Status vocabulary (21 "Evidence classes"; every claim names its class):

- **DB (EXECUTED_LOCAL on `b07/design`)** — the database half of the case: the named test exists on this branch under exactly
  that name, runs against a real PostgreSQL 17 cluster it starts itself, drives every write through the runtime login role that
  owns it (`kauro_app_test` as a request handler, `kauro_control_test` as the control plane bound to one agency) and passed in
  `pnpm run verify` of this branch. It proves what the database refuses and admits whatever the application does.
- **SPECIFIED (mandate)** — the command-, pipeline- or parser-level half: the design fixes the exact behaviour (§11, §12) and the
  row names the test the implementation mandate writes (planned file :: planned title). A SPECIFIED row is not claimed.
- **SIMULATED** — a clause demonstrated only through a labelled contract fake of a provider port (object storage, malware scanner,
  session vault, authority journal; provider tokens `contract-fake-*`, evidence class SIMULATED). Until B15 binds the real
  adapters these clauses are never EXECUTED_PROVIDER.
- **LATER** — a clause another package owns, named with the package and its registry case where the registry has one.

No case is PASS by being listed; acceptance is the construction service's independent review. The planned tests follow B06's
placement (command cases through the real HTTP route and composition root in `apps/api/test/`; database facts in
`packages/persistence/test/`; parser facts in `packages/data-plane/test/`; control-plane pipelines in `apps/control/test/`), every
fixture writes as the role that owns the write (`@kauro/persistence/testing` source-lifecycle fixture), interleavings are fixed by
lock-wait observation, never by time, and the oracle is the superuser reading every table.

Short names used below: **SM** = `packages/persistence/test/source-migrations.test.ts`; **SC** =
`packages/application/test/source-contracts.test.ts`; **DM** = `packages/domain/test/source-model.test.ts`.

## Gate G-UPLOAD

Owner 09; evidence rule: exact subject, public consumer, independent truth, complete result, meaningful negative control and
reviewer acceptance; verification clause of every case: "Enumerate raw/derived/residual classes and restore after deletion; an
application boolean is insufficient."

- **Raw/derived/residual classes**: the object registry records every generation with its zone and data class (RAW, DERIVED,
  RESIDUAL), its state, deletion result and provider residual (D-OBJ-1, D-OBJ-2); SM :: "R2-051 at the database: …" and :: "B07
  tables force row-level security, …" observe it. The DeletionReceipt that enumerates them for a scope and the comparison with
  provider inventory are **LATER: B16** (G-DELETE, CMD042 RequestDeletion, CMD060; S063–S065, R2-053).
- **Restore after deletion**: the authority tombstones are appended outside the database (D-RESTORE-1, SPECIFIED B07-CONTROL
  `apps/control/test/authority-journal.test.ts` :: "tombstones of cancelled, expired and superseded authority are appended once and
  listed in sequence order"); restoring a backup and applying them before traffic is **LATER: B16** (09 "Deletion receipts and
  restoration"; 09 "Acceptance and operating checks" restoration tests).
- **An application boolean is insufficient**: admission is a receipt with separate results and a composite key to the promoted
  generation (DB tests), never a flag; `FileManifest.admitted` is derived and a browser cannot set it (SC request schemas).
- **EXECUTED_PROVIDER** evidence of storage, scanner and session cancellation is **LATER: B15** (real adapters); B07's provider
  clauses are SIMULATED until then.
