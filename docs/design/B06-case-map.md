# B06 — case map

Every case of package B06 (registry `cases.json` / `additional_scenarios.json`, gate G-DOMAIN) mapped to the test that
demonstrates its expected outcome and to what a sealed check observes. Design: `docs/design/B06-domain-db-authz.md`.

Status vocabulary (21 "Evidence classes"): **EXECUTED_LOCAL (branch)** — the named test exists on `b06/design` and passes
against a real PostgreSQL 17.6 started by the test; **IMPLEMENTATION** — the test is specified here and written by the B06
implementation mandate together with the handlers/adapters/api it exercises. No case is PASS by being listed
(reference/ACCEPTANCE_SCENARIOS "Execution record"); acceptance is the construction service's independent review.

Test locations: command-boundary tests live in `packages/persistence/test/commands/` (the adapter package is the only layer
that may depend on domain, application and `pg` at once — `architecture.rules.json`); HTTP-boundary tests live in
`apps/api/test/`. Every test starts its own cluster with `startTemporaryPostgres()` and asserts with the superuser oracle
(sees every tenant) against the runtime login roles (see every policy).
