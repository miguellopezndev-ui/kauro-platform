One `AttemptByteLedger` keyed by path: charged(path) bytes, live = their sum, path = path.resolve (lower-cased on win32; links and hard links are refused, so a file has one key). (1) parent inputs: input k reserved at its capability byteLength before its first byte; a stream past that length is cut (SOURCE_INTEGRITY_FAILED) before the excess is written. CONTROL (no byte change; the fd must come from the preload's openSync): `closeSync`, `fsyncSync` (r5, D16), `mkdirSync`. REMOVAL (credits by (5)): `unlinkSync`, `rmSync` (recursive/force as MC calls it), `rmdirSync` (r5, D16; non-recursive only, a recursive option -> OUTSIDE_CAPABILITY), `renameSync`. (4) parent spools: file k staged only if io.scratch live + remaining package bytes + size_k <= B (spool of k = size_k, known from the child's record); file k deleted after its close. (5) Credit rule (r5, D06): a removal or replacement credits exactly the charged bytes of the keys that ceased to exist, read from the ledger's own map, never an lstat size (a directory's lstat size is 4096 on ext4 and 0 on NTFS, unrelated to its content): unlinkSync(p) credits charged(p); rmSync(p) and rmdirSync(p) credit every key equal to p or under p + separator; renameSync(a, b) first credits b's keys (the file or tree replaced), then re-keys a's entries under b (no credit: the bytes still exist); openSync(p, w) and writeFileSync(p) over an existing file reset charged(p) before charging. A call that throws midway (EPERM, ENOTEMPTY) is followed by a reconcile: each charged key under the target is lstat-ed and credited only on ENOENT, so a partial removal credits exactly what vanished. Directory entries and metadata are not data bytes (charged 0); the device backstop bounds them. The parent uses the same ledger class for inputs and spools; the child record carries its residual map (the staging package files), which the parent adopts and credits per file as it stages and deletes it. MC's verifyAgainstSource tmpdir write is outside the permission model's allowed paths -> OUTSIDE_CAPABILITY (not used by verifyPackage; M23 asserts).
