## Bounds that follow from the contracts

- One worker task-hour: 2 × 0.04048 + 8 × 0.004445 + 52 × 0.000111 = **USD 0.122292** (USD 0.00204 per minute, one-minute minimum).
- One attempt at its 8 h wall: USD 0.98; one job at three attempts: USD 2.94.
- With heavyActive = 1 the worker can never run more than one task at a time: at most USD 89.27 of Fargate in a month even if it never stopped. That is above a plausible early ceiling, which is why R2-075 makes the application's reservations and job limits the cap and the budget only a lagging backstop.
- The worker's interface endpoints cost USD 21.90 a month whether or not a task runs (PrivateLink bills per endpoint-hour). They exist only while `worker_enabled = true`; with it false no task can pull its image or log, so the worker fails closed rather than costing money.
- A public IP instead (USD 0.005/h only while a task runs) would be cheaper and is rejected: it gives code that handles customer data an open path to the internet (B14-A qualification §4).
- Database floor: RDS PostgreSQL 17 db.t4g.micro with 20 GB gp3 = USD 13.98; Aurora PostgreSQL Serverless v2 kept awake at 0.5 ACU with 20 GB = USD 45.80 plus I/O. Aurora pauses only with no open connection, which a pooled control plane never gives it.
